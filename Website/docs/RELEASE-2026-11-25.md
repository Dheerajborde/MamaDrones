# Release defense — 2026-11-25

## Scope and decision

The public site presents Mama Agricultural Robotics, drone products and services, Pehelwan, the company journey, and a contact route in English and Marathi. The owner asked to fix production issues and merge the review branch. This release keeps the redesign's product copy and media while repairing dependency, language, sitemap, responsive, media, and form disclosure issues. The baseline is `main` at `7fc9d9d`; it is a recovery source revision, not a proven good release. AI model/version is unavailable in the project record.

Next.js 14 had known advisories and was outside support. Upgrading to Next.js 16.4.6 with compatible React, image, icon and lint packages was chosen over patching an old unsupported line. Unused packages were removed to reduce exposure. Webpack is selected in the scripts because the local Turbopack build failed on the Mapbox CSS pipeline; this costs some build speed. Separate English and Marathi root layouts were chosen over a client language change so crawlers and no-JavaScript users receive the correct HTML language. The 17.5 MB WebM was re-encoded and an H.264 MP4 fallback added to reduce data usage and broaden playback. The original supplied source video was not changed.

## Execution path and data

- Next App Router receives `/`, `/drones`, `/electric-tractor`, `/our-journey`, `/contact` and their `/marathi` equivalents. Route group layouts emit `<html lang="en">` or `<html lang="mr">`; `SiteChrome` chooses the corresponding navigation and footer. Dynamic drone slugs are bounded by the four entries in `src/lib/site-data.ts` and return 404 for unknown slugs.
- `src/app/sitemap.ts` derives nine route pairs from the same bounded drone list and emits both language alternates. No visitor data is retained by this code.
- `CountUpValue` reads fixed company-reported November 2026 targets. It animates only on intersection, exposes final values to assistive technology, and leaves final values visible for no-JavaScript or reduced-motion visitors. It does not fetch or persist data.
- `TractorVideo` plays a local muted loop at 0.5× speed while in view and pauses outside it. With reduced motion or blocked autoplay, its poster remains. The two local encodings are under 1 MB each.
- The contact page passes the selected topic as display guidance; Formfacade's external embed collects name, email, phone and location and submits to Google Forms. The site does not store that submission. The form provider and its Google destination are the external trust boundary. The site now warns visitors about that transfer and discourages sensitive details. The operator controls access and retention in those external services; those settings were not inspected or changed.
- Optional Mapbox functionality reads `NEXT_PUBLIC_MAPBOX_TOKEN` from the host environment. This is a client token, not a server secret. If absent or the service fails, the page still shows the office address and phone information.

## Actors, misuse, limits and recovery

Visitors can browse public claims, follow contact links, and submit the external form. Search crawlers read the static metadata/sitemap. The owner controls claims and media rights; the form and map providers control their respective services. Realistic misuse includes spam or sensitive data entered into the form, misleading copied pricing/figures, and high data use from media. The form's provider handles its own anti-spam and availability; the page asks visitors not to send sensitive information and offers phone contact. Figures are labeled company-reported and Pehelwan price/design statements are qualified. Media now has smaller files and a poster. This code has no database, privileged server mutation, payments, or hardware control. Third-party outages can prevent form/map use; users can call the listed numbers. Delivery is detected by a confirmation state plus owner inbox check, not by client logs alone.

The owner approved the claims, Marathi wording and media rights for public use. A labeled dummy enquiry was submitted on 2026-11-25, showed “Your response has been recorded,” and the owner confirmed receipt. The Marathi page layout matches English, but Formfacade still supplies English field labels. A browser error appeared from the embed during load; the form completed the test path despite it. Revisit if the provider changes or submissions fail.
